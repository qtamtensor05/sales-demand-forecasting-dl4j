# Project completion workflow

For work in this repository, read and apply
[sales-project-progress](.agents/skills/sales-project-progress/SKILL.md).

After each completed user request, update the Vietnamese documentation in `docs/`
with the objective, reason, implemented changes or findings, verified results and limitations.
Include a suggested commit title in the log and final response.
Read the skill for rules on investigations, title-only requests, and avoiding recursive logs.

Keep project code compatible with Java 11. Preserve train-only normalization and chronological
split boundaries when changing preprocessing. Document any intentional change to those rules.
Do not commit or push solely because this workflow asks for a commit title.
